Prior week — Engine & AI refactor (UE 5.8.2)

Completed before the current October content pass (the 4,000+ file activity scan includes this engine work plus later asset edits).

Summary

Snack Ops SDK engine version migration and stability sweep: critical movement bugs, legacy API deprecations, and a UE 5.8 physics regression fix to restore performance in line with the custom 5.3.2 build.

Movement & navigation refactor

  • Ledge stability: Third-person movement when walking on, near, or falling off ledges.
  • Navigation core: Foundational AI pathfinding + Character Movement Component (CMC) navigation improvements.
  • API modernization: Character acceleration was ignored due to deprecation.
    • Old (ignored): use_acceleration_for_paths on CMC
    • New (active): NavMovementProperties.bUseAccelerationForPaths

Chaos physics & engine fix (~30% performance)

Stress tests showed ~30% navigation/physics substepping cost vs. the old build.

  • Symptom: CPU hitch on heavy runtime (grenades, shoot-while-move).
  • Gameplay: AI tracking lag → movement desync, panic, visible pops/teleports.
  • Root cause: UE 5.8 regression — AddUnique() validation on a large array every physics step.

Source build patch — Engine/Source/Runtime/Experimental/Chaos/Private/Chaos/PBDRigidsSolver.cpp

// Changed from:
PendingDestroyPhysicsProxy.AddUnique();

// Changed to:
PendingDestroyPhysicsProxy.Add();

Removes duplicate-check tax on that array; regains the ~30% and reduces physics micro-stutters.

Launcher build workaround (no source compile)

On Epic Launcher binaries you cannot patch .cpp. Mitigation for local testing:

  1. Select high-poly map assets (houses, modular fences, roofs) in Content Browser.
  2. Right-click → Asset Actions → Bulk Edit via Property Matrix.
  3. Set Collision Complexity from Use Complex Collision As Simple → Project Default.

Iron Will Interactive — 8/31/2026 · Future: proper UCX collision meshes for launcher creators.

We ship a dedicated Snack Ops HQ Launcher (Electron) for this SDK — play/test builds, DEVELOP (clone this repo with Git LFS, open Unreal), standard mod packs, and bundled UGC with an in-app Gun Import Guide.

HUD Death quotes

  • BP_MainHUD uses an Array of Text variable DeathQuotes (not the old enum-driven death message pin).
  • All 15 lines from E_DeathMessages moved into default array values (war-themed copy, no display asterisks).
  • Paste workflow: copy widget Default Values (Tagged JSON), edit display strings only, paste into Details → DeathQuotes → Default Value. Template: TextArray.json (keep NSLOCTEXT keys when expanding count).

Aim Crosshair — third person vs first person

  • Third-person crosshair tuned to line up with first-person at common engagement distances — fewer odd offsets.
  • Planned: dynamic convergence so FP/TP reticles stay aligned at all distances. This pass is an improvement, not the final system.

World Ladders, zones & UI triggers

  • Procedural ladder system — overhauled and added back; climb/detach tuned on BP_Ladder (procedural placement/behavior pass).
  • Icon trigger zone → UI message — entering marked volumes shows contextual HUD prompts (icons + copy). Wired through course/help actors such as BP_CourseTrigger, BP_Help, and help marker materials.
  • Stage zone system — labeled stages for modes like target practice, course legs, and other training slices via BP_CourseVolume / trigger settings (per-zone rules and messaging).
  • Ballistics meshes — millimeter-accurate bullet static/skeletal meshes for tracers and projectile visuals (caliber-true sizing).
  • More stage types and messaging strings can be appended here as you finalize names (same October content wave as maps, Free Roam, and import guides).
